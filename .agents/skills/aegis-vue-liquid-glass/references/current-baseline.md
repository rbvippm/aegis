# 已确认的首页实现基准

2026-10-25 起，后续 UI 以本文「UI 模板」为准。首页、监测、AI、体育对比、我的、订阅和服务页均已实现；早期“其他页保持占位”的说明不再授权回退。用户对具体页面的新指令仍优先于模板。

## UI 模板

后续主页面、二级页、抽屉和下拉都按这一节制作。颜色变量在 `src/shared/styles/tokens.css`，不要在新组件里再写一套蓝。

### 颜色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 页面底 | `#F5F8FF` | 应用背景 |
| 表面 | `#FFFFFF` | 卡片、抽屉内容、下拉触发器 |
| 控件边 | `#D7E6F8` | 白卡片、分段轨道、下拉、筛选项 |
| 正文 | `#14213D` | 标题与正文，字重 650–700 的标题 |
| 次级 | `#526581` | 说明、时间、未强调标签 |
| 标签蓝 | `#3D5D86` | 分段里未选中、信息条文字 |
| 高光 | `#0864FF` | 链接、图标、当前数字、排序 |
| 选中胶囊 | `--ae-pill`：`#57AEFF` → `#0872ED` | 分段选中、主按钮。白字。阴影 `--ae-pill-shadow` |
| 涨 | `#087F6B` | 赔率上升、正向结果，配图标 |
| 跌 | `#C4273D` | 赔率下降，配图标 |
| 暂停 | 字 `#8A6424`，底 `#FFF6E4` | 暂停报价，不和跌红混用 |

选中胶囊不要再用 `#2563EB`、`#0959DC`、`#0663F9` 这类中间压深的多段渐变。`#2563EB` 只留作焦点环。订阅三个等级保留各自表面，不套胶囊蓝。

### 字号

系统字体栈，数字 tabular-nums。正文 400，标签 500–600，平台名 600，标题 650–700。不把整段中文都加粗。

| 角色 | 字号 / 字重 |
| --- | --- |
| 品牌 | 23 / 700 |
| 页面主标题 | 24–28 / 700，窄屏可到 23 |
| 区块标题 | 17 / 700 |
| 卡片内标题 | 14–15 / 650 |
| 正文、主按钮 | 14–16 / 400–650 |
| 分段、筛选项、下拉 | 13–14 / 600–650 |
| 说明、时间、辅助 | 12 / 500 |
| 底栏 | 11 / 400，当前项 600；不把 11px 用到正文 |

10–11px 只允许底栏和极次要时间。盘口、平台分、表格和操作不用这个字号。长名称单行省略，不把格子撑成两行。

### 布局

应用栏 `min(100%, 430px)` 居中。截图基准 390px，同时看 360 和 430。主内容左右 12px，头部左右 20px。卡片内边距 12–16px，区块间距 8–12px。卡片圆角 16–20px，控件圆角 14–16px，胶囊轨道约 16–18px。触控目标至少 44px；视觉可以更紧，用内边距或负边距保住点击区。页面不能横向溢出。

### 控件

- 分段：白底轨道加 `#D7E6F8` 边。未选中 `#3D5D86` 或 `#14213D`，选中用 `--ae-pill` 白字。
- 主按钮：同一颗 `--ae-pill`，白字，高度至少 44px。次按钮白底、蓝字、同色边。
- 下拉：只用 `shared/ui/GlassSelect.vue`。触发器白底、`#D7E6F8` 边、13–14px / 650、蓝色箭头。菜单白底，选中项 `#0864FF` 字和 `#E7F2FF` 底。不要新的原生 select 弹层。
- 信息条：左文右数，数字 15 / 700 `#0864FF`，项与项之间用 3px 圆点。
- 涨跌图标：18px 实色块，白图标，涨绿跌红，不靠淡色描边。
- 抽屉：一个主标题。高度不超过当前可视屏幕 80%，拖动时也不超过。慢拉半收起，快拉或长拉关闭。
- 玻璃只用于底栏、搜索和少量浮层。表格和长列表用实色白底。
- 过渡 150–180ms，按压缩放约 0.98。`prefers-reduced-motion` 时取消位移和缩放。

### 不要

不画设备外框、地址栏或 Telegram 标题栏。不新增“演示数据 / 演示体验”提示。不伪造模型、钱包、专属经理姓名或链上连接。接口失败不静默退回 mock。

## 布局与字体

应用栏所有主路由为 `min(100%, 430px)`，桌面居中。390px 是截图比较基准，同时检查 360/430px；主内容左右 12px，头部左右 20px。首页保持紧凑信息顺序，禁止回到 1100px 的营销布局。

| 元素 | 字号 / 字重 | 补充 |
| --- | --- | --- |
| 品牌 | 23px / 700 | 雷达标记 34×34px，冰川蓝 #0864ff |
| 首页主标题 | 25px / 700 | 360px 下 23px；行高 1.4 |
| 介绍副标题 | 13px / 600 | 蓝色 |
| AI 卡标题 | 22px / 700 | 窄屏 20px；字距 -0.6px |
| AI 副标题 | 14px / 400 | 窄屏 13px；行高 1.45 |
| 输入文字 | 16px / 400 | 保留中文组合输入处理 |
| 区块标题 | 17px / 700 | 行高 1.4 |
| 四入口标签 | 13px / 500 | 不额外添加多行描述 |
| 平台名称 | 13px / 600 | 避免过粗 |
| 状态 | 12px / 400 | 窄屏可为 11px |
| 耗时数字 | 14px / 650 | 主摘要数字 30px / 700 |
| 时间说明 | 10px / 400 | 仅极次要元信息，不用于正文；优先删减重复说明 |
| 底栏文字 | 11px / 400 | 当前项 600，AI 为 12px / 500 |

系统字体栈使用 -apple-system、BlinkMacSystemFont、PingFang SC、Microsoft YaHei、sans-serif，数字保持 tabular-nums。字体粗细不能仅依赖截图印象，需检查实际计算值；不要将全部中文改成粗体。

## 视觉衔接与交互过渡

- 标题区高 125px，背景下缘叠加渐变，向 AI 卡衔接使用约 -5px 的轻微重叠，不出现生硬色块接缝。
- 角色切换由独立滑块完成：220ms、cubic-bezier(.22,.8,.25,1)，三个按钮等宽；文字颜色 160ms。不要在切换时改变按钮尺寸或页宽。
- 页面切换 opacity + translateY：150ms；进入位移 4px、离开 -3px，out-in。不要动画 height、blur 或让固定底栏随页面淡出。
- 点击反馈约 150ms，卡片/建议行缩放 .98、发送 .92、导航 .93；输入聚焦边线与阴影约 180ms。不增加悬浮卡片上跳等桌面动效。
- 遵守 prefers-reduced-motion，取消相关过渡；减少透明度模式及无 blur 环境保留实色浅蓝、轮廓和文字层级。
- 截图必须等页面过渡结束再保存；中间帧的低透明度不能用作批准截图。

## 底部导航

- 所有主路由共用 FloatingDock；占位 AI 页也显示底栏，只有后续明确设计专注聊天时再评估隐藏。
- 固定居中，宽 `min(100% - 16px, 414px)`，底部为 `8px + safe-area`；高度 66px、圆角 30px，五列等宽，不能随路由改变轮廓。
- 白色高光边缘、乳白到冰蓝渐变、下缘冷蓝内影与柔和外影；blur 18px、saturate 150%，提供无 blur 降级。
- 图标：首页 House、监测 Database、对比 ChartNoAxesColumn、我的 UserRound，约 24px / 1.9 线宽。AI 单独使用一颗四角星芒 SVG，不使用多颗 Sparkles 或 emoji。
- 中央 AI 球 58×58px、50% 圆角、白色双环、内部高光、蓝色径向渐变，顶部上凸约 8px；31px 星芒与 AI 标签上下居中。不能改成横向胶囊。
- 普通图标为轮廓，当前首页可实心；只给当前路由 aria-current。AI 常驻突出不等同于 AI 页面已选中。
- 每项最小操作高度至少 44px，保留 focus-visible；正文有足够底部 padding，滚到底时最后一项可完整露出。

## 验证与交付

页面视觉修改需保存同尺寸前后截图并检查首屏顺序、字号、字体、玻璃边缘和底栏；功能测试通过不代表像素级一致。按本次变更运行类型、lint、单元测试和构建，涉及路由/导航时运行移动端 e2e。当前 e2e 检查首页到占位页、二级入口文案和 360/390/430px 无溢出。开发服务使用 127.0.0.1:6173，不自动发布。

## 2026-10-24 最新交互与文案调整

通用抽屉上拉最高限制为当前可视屏幕的 80%，拖动中也不超过；普通下拉可半收起，快速或长距离下拉关闭。默认打开时聚焦对话框容器，避免手机把手自动出现蓝色焦点框，保留键盘 focus-visible。新增功能不默认附加“演示数据”“演示体验”等重复提示；数据模式保持在配置/adapter 层明确，不伪造服务连接与实时状态。
