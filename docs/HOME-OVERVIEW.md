# 首页功能总览

2026-10-24 将用户确认的首页方案落实到 `/`。按最新要求移除下方“专属服务”“我的工作台”区块，保留顶部 VIP 服务和代理比价快捷入口。沿用原品牌素材、HomeBanner 四页轮播、冰川背景和 FloatingDock。

## 内容与交互

- 品牌栏：消息中心进入 `/me?section=messages`；搜索打开共享 BottomDrawer，搜索当前收录的球队、联赛和平台，包含空输入、无结果、API 未接入状态。
- 角色条：默认用户；代理进入现有代理比价；平台打开合作说明，反馈入口仅保存原有个人中心草稿，不伪造已提交入驻。
- AI：复用 AiOrb 与 AiComposer，保留中文输入法和 Enter 行为。两条建议带问题进入 AI，保持只预填、不自动发送。
- 四入口：出金监测、赔率对比、VIP 服务、代理比价。
- 赛事与机会：热门足球、理论套利候选、滚球动态三种状态。热门报价复用赛事 mock 的有效报价，剔除暂停和过期项；较优价按同市场、同侧计算。赔率制式支持 HK/MY/ID/DEC，与对比页共用可选本机偏好。
- 理论机会仅纳入允许简单双结果计算且覆盖完整结果的市场，不将理论价差表述为可执行净收益。报价、限额、费用和有效期仍需核验。
- 平台资金监测：平台 A 小额平均出款、已知热钱包汇总、样本与来源、平台 B 资金异动。汇总排除平台 C 缺失余额；按现有样例为 $67.4M（2/3 家已知），不抄用设计稿示意数字 $88.4M。不虚构出款同比、按链均值或连续耗时曲线。
- 平台榜单：综合盾牌分和赔率竞争力分开。实际样例评分为 A 9.2、B 7.1，C 样本不足、不赋予名次。赔率竞争力按同口径有效样本的最优报价占比降序，跳转到对比榜单。
- 页尾：帮助与客服、意见反馈、关于我们，深链接打开现有个人中心对应抽屉。

## 联动

对比页接收经过白名单校验的 `view=odds|arbitrage|ranking`、已知 `match`、对应 `market` 和 `platform`。`panel=quote|market|opportunity|movements` 分别展开有效报价、结算规则、机会核验与滚球记录；原 `panel=reminders` 保留。未知 ID 和 API 模式不打开模拟业务。

监测页支持 `platform=A|B|C` 定位详情；`panel=flow` 打开资金异动。个人中心仅允许首页使用 `panel=help|feedback|about` 的公开说明入口，不开放任意面板深链接。

## 数据与边界

首页没有新增真实接口，也未接入模型、知识库、链上或赛事服务。仅 demo 模式展示现有独立 mock；API 模式显示暂无数据，不回退样例。搜索也不伪造全网结果。固定记录不按当前时钟更新；来源和样本解释放统一详情抽屉，避免重复装饰文案。

首页摘要逻辑在 `features/home/overview.ts`；布局与交互在 `HomeOverview.vue`、独立前缀 `home.css`；原轮播继续独立维护。没有改动已有 AI、VIP、代理的独立工作区修改，没有提交或推送。

## 验证

- `npm run check`、`npm run build`：通过，33 项单元测试。
- 首页 11 项移动端测试通过（7 项总览与跨页交互、4 项原轮播），覆盖360/390/430px、页尾底栏避让、搜索、格式切换、抽屉和跳转。
- 全站63项浏览器回归：59通过、4失败。失败均在已有 AI 页相关用例：同文案出现两次导致选择器歧义、未知问题旧文案断言，以及欢迎页按钮被 ac-hero 遮挡导致发送/历史用例失败。本轮未改动该 AI 页面或覆盖其独立样式修改。
- 实际截图已查看：`outputs/home-implementation/home-390.png`、`bottom-390.png`；另保存360/430px截图。保留原图标系统和现有发送箭头方向，数值与真实已有 mock 保持一致，不宣称逐像素无差异或已接入实时服务。

## 首页 UI 走查（移除角色条后）

按最新意见移除“用户 / 代理 / 平台”整行及专用样式，品牌栏直接衔接冰川轮播。代理服务仍从原四入口进入。

修复自动轮播横向移动时标题短暂被裁切的问题：自动播放整页切换，手动切换保留滑动，继续支持原生触摸滑动、键盘与减少动效。增强非选中轮播点的可见度。

主要分段、建议问题、盘口入口、来源及榜单说明操作区提升至44px高；赔率制式改为带顶部细分隔线的完整一行，去除负边距贴边。加深辅助文字、将榜单次级标签统一到12px，并补充搜索聚焦边界、长文本换行、行内图标防压缩和点击反馈。

验证：33项单元测试、`npm run check` 与 `npm run build` 通过；首页、轮播、UI走查和导航23项浏览器测试通过。实际查看首屏、滚球与搜索抽屉截图，360/390/430px全部保存于 `outputs/home-audit/`。本轮未重跑前述全站AI失败用例，不将这23项的通过描述为全站通过。真实系统键盘与Telegram宿主未实机验收。

## 首页颜色与字体复核

按设计规范再次读取390px实际计算样式并保存前后截图（`outputs/home-colors/`），只调整首页新增模块及其详情样式。

- AI标题21→22px/700，副标题13→14px/400；360px分别20/13px；输入保持16px。
- 区块标题17px/700，明确1.4行高；主要分段标签14px/500，盘口文字14px/400，辅助说明12px/400。
- 资金摘要26→30px/700，单位16px/500；平台名称14→13px/600，评分17px/650。数字保持tabular-nums。
- 复用 `--ae-primary`、`--ae-text`、`--ae-muted`、`--ae-warning`、`--ae-danger`，收敛独立蓝色和灰色；分段玻璃保留高光，文字所在区域加深。
- 抽样色组对比度：正文/白底15.97，辅助/浅蓝5.40，链接/浅蓝4.65，危险/浅红5.95，警告/浅黄5.15，白字/主蓝5.17。玻璃渐变不能用单一比值代表整层，另以截图检查文字区域。

验证：360/390/430px切换、长文本、抽屉、页尾及底栏检查通过；23项相关浏览器用例、51项单元测试、check与build通过。实际查看了360px首屏和390px页尾；三种宽度状态截图仍保存于 `outputs/home-audit/`。
