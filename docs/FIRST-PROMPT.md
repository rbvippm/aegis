# 在正式项目中使用的启动提示词

Codex 先调用 `$aegis-vue-liquid-glass`；Cursor 先用 `/` 选中同名技能。然后发送下面正文：

---

请读取 aegis-vue-liquid-glass 技能、其中的批准设计图，以及当前项目的 AGENTS.md、package.json 与锁文件，开始 Aegis 第一阶段开发。

目标：Vue 3 + TypeScript 的移动端应用，共用 H5 与 Telegram Mini App 页面。沿用已有项目结构；如果目录确实为空，以 create-vue 初始化并启用 Router、Pinia 和适合当前阶段的检查工具。先简述实际技术选型，然后执行。

设计：冰川蓝 #2563EB，浅背景 #F5F8FF，iOS 26 Liquid Glass 风格的悬浮导航、输入框和按钮；长文本与数据表保持清楚。构建真实页面，不把手机外框、地址栏或 TG 原生标题复制进应用。

范围：先实现首页、AI 对话、四维比赛分析、盘口结论、同盘口赔率排名、带样本量的出入金排名、来源引用和继续追问。首页有直接问 AI 输入框，底栏：首页/监测/AI/对比/我的。其余页面先提供可用路由与明确空态，不扩展 VIP/代理完整业务。

先使用独立 mock adapter，所有虚构数据显著标为演示，不接真实密钥或假装已经接入大模型。真实模式预留结构化 API 接口，数据缺失、过期、样本不足时有对应状态。不要把“出金更快”表述为资金安全保证。

双端通过 platform/web.ts 与 platform/telegram.ts 适配。普通浏览器不依赖 TG 环境；TG 能力按支持情况启用。处理 History 路由、启动参数、安全区与键盘。模型与 Bot 密钥只在服务端。

实现后运行实际 package.json 中的类型检查、构建和必要交互测试；能用浏览器时检查 360/390/430px 截图。报告完成范围、验证结果和未接入项。暂不部署或发布。
