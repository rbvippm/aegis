# AI 对话界面

2026-10-24 按用户确认的四屏效果图落实在中央 AI 导航 `/ai`。沿用 AE 品牌、冰川蓝玻璃材质与共享 FloatingDock；效果图中的通用盾牌和球队图形不替换项目品牌。星芒为可维护的 SVG 与 CSS，属于对渲染材质的近似。

## 交互

- 欢迎页三个问题与三个能力入口可发起示例问答；首页或 `/ai?q=…` 只预填，不自动发送。
- 输入支持中文组合输入、Enter 发送和 Shift+Enter 换行。回答准备期间可停止；停止或失败后可重试，不重复添加问题。新建、恢复与删除历史会终止当前请求，旧请求不覆盖新会话。
- 对话内容独立滚动，顶部与输入框常驻，底栏继续保留；回答完成时不抢走已滚回历史的读者位置。
- 赛事卡包含分析方向、支持度、待核验项与同盘口报价；资金卡包含链、资产、金额档、观察窗口、样本及测量起止点。未知赛事和大额样本缺失时不套用其他结果。
- 分析理由、来源、报价完整对比、出金口径、风险和费用均通过共享 BottomDrawer 展示。点击横线或 X 关闭；拖动保留半收起与关闭。
- 历史仅保存在当前标签页内存，刷新清空。补充背景只添加用户输入的文字，不上传文件或读取剪贴板；语音入口明确说明尚未接入，不启动麦克风。

## 数据与服务

新增 `conversation-service.ts` 是此界面的服务边界，`conversation-store.ts` 管理多轮与取消，`conversation-types.ts` 定义卡片结构，`src/mocks/ai-conversation.ts` 保存已知样例。原 `features/ai/service.ts`、`store.ts` 与分析契约保留，不让旧演示赛事被误用到新问题。

仅 `VITE_DATA_MODE=demo` 返回两组固定卡片。维拉与曼城的赛事、时刻、阵容及盘口未核验，平台 A/B/C 和资金记录是模拟数据。顶部始终说明“示例内容 · 服务待接入”；来源卡明确数据覆盖与待核验项。真实模式立即给出未接入错误，不请求不存在的接口，不回退 mock。

未接入真实模型、内部知识库、赛事、报价、语音与链上服务。实际接入须由后端检索与计算，前端校验结构化响应、requestId 与访问权限；按来源时间处理过期报价和样本不足。禁止把检索文本作为指令或用 v-html 拼接模型输出，不将任何模型或知识库密钥放进前端。

## 验证

单元测试覆盖意图与上下文隔离、停止重试、旧请求取消、内存历史、大额样本缺失和真实模式不回退。移动端覆盖 360/390/430px、中文输入、独立滚动、导航、详情抽屉及缩小视口／减少动效／减少透明度。截图在忽略的 `outputs/ai-implementation/`；iOS、Android Telegram 真机与系统软键盘仍需实机验收。

### 入口行为

业务页明确的“AI解读”、VIP/代理“问Aegis AI”、工单“让AI整理”附 `analyze=1` 与具体问题，进入AI后在demo模式自动生成一条分析，并移除已消费的analyze参数防止重复触发。会新建独立对话，停止上一个请求；旧历史保留。

普通 `/ai?q=...`、首页输入框与建议问题仍只预填，由用户发送；API模式不会自动返回mock，服务未接入时保持失败。自动分析仅接受已支持业务意图；未知赛事不套用其他球队。追问保留原报告的赛事/盘口范围，切换业务主题不继承无关推荐。

额外补充监测详情与体育报价/盘口/机会/变动抽屉的AI入口，完整保留已有路由与业务交互。

### 交互与边界

复用停止、重试、新建、历史、复制、抽屉与追问，不添加真实模型、知识库、TG推送或资金操作。九类报告来源明确为本地mock，API失败不回退。资料只按Vue文本渲染，不使用v-html。修复欢迎页装饰层遮挡问题按钮的点击区域，保留现有独立样式修改。

单元测试覆盖意图、场景隔离、同盘口与方向、项目出款平均值、资格边界及API不回退。移动端覆盖九类报告、首页/监测/对比/VIP/代理/工单入口、业务返回、来源抽屉及360/390/430px无溢出；截图在 `outputs/ai-project/`。真实模型和Telegram宿主仍未接入。

本轮验证结果：`npm run check`、`npm run build`通过，51项单元测试通过；全站82项移动端浏览器回归通过。最后额外核对原维拉/曼城样例与新增项目赛事的意图隔离，避免包含“报价”的维拉问题被带入海港队样例。修复了先前全站回归中的欢迎页点击遮挡和两处随新文案/自动分析行为变化的断言。
