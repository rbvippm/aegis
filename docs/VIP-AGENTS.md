# VIP 服务与代理比价

本轮仅新增首页两个二级入口对应的界面与演示交互；保留已有首页、AI、监测与体育对比。未接入真实平台、报价、身份核验、竞价、托管或仲裁服务。

## 页面与结构

- `/me?section=vip`：返回首页 → 冰川介绍与匿名报价入口 → 三步流程 → 专属报价 / 匿名充值榜 / 我的需求 → 方案卡与排行 → 出金监测、AI 入口 → 现有常驻底栏。
- `/me?section=agents`：返回首页 → 冰川介绍与匿名合作入口 → 三步流程 → 佣金比价 / 信誉档案 / 团队竞价 → 政策表、试算、履约证据、团队入口和担保规划 → 辅助入口 → 现有常驻底栏。
- `/me` 仍为原占位页。导航选中“我的”。二级页有独立浏览器标题。

视觉沿用共享 Liquid Glass 技能、当前首页字体与品牌、原冰川背景、五项底栏。冠形与团队图标为现有 Lucide 图标的 CSS 材质近似，没有将生成效果图栅格化嵌入页面。

## 可操作内容

VIP：按平台筛选；按等级、Lossback、日返水排序；查看每家来源及完整条款；加入或移出双方案对比；切换 30 / 90 日匿名排行；阅读盲拍与隐私说明；创建、编辑、清除匿名需求。

代理：按佣金模式、结算周期和场馆费筛选，包含空结果与重置；打开各平台政策来源、扣量与锁佣条款；自定义净收益、双方返佣率、场馆费和其他扣减进行试算；查看评级方法与缺失证据；创建、编辑、清除团队需求；查看担保仲裁后续规划。

两个页面的出金监测入口进入现有监测页；AI 入口携带对应咨询问题进入现有 AI 页，不自动发送问题。

## 数据与计算边界

- `src/mocks/services.ts` 独立维护虚构平台、条款与区间排行，固定日期为 2026-10-24（UTC+8）。来源明示为本地演示，无伪造外部链接。
- 仅 `VITE_DATA_MODE=demo` 展示报价、排行、试算及会话内需求；`api` 模式显示尚未接入，禁用创建入口，不回退到 mock、不发送请求。
- VIP 平台 A：VIP 6、8% 月 Lossback、每月上限 2,000 U、0.8% 日返水。平台 B：VIP 5、10% 周 Lossback、每周上限 1,000 U、0.6% 日返水。名义比例不直接代表实际待遇。
- 佣金示例：A 返佣 40%、场馆费 8%；B 返佣 45%、场馆费 12%。按净收益 10,000 U 且其他扣减为零计算，分别为 3,680 U、3,960 U。
- 自定义试算口径：`max(0, 净收益 × (1 − 场馆费率) − 其他扣减) × 返佣比例`，结果四舍五入至 0.01 U。跨期负盈利不自动计入。空值、非有限值、负数及超范围费率拒绝计算。
- 代理信誉没有真实样本，统一“样本不足，暂不评级”；无投诉数据不等同于信誉良好。
- 需求仅在 Pinia 当前会话内保存，刷新即清除；不写入本地存储，不上传资料、不请求接口、不向平台发送，也不自动生成真实报价。
- 担保仲裁明确为后续规划；不接收资金，不提供托管或赔付承诺。
