# 2026-10-25 UI 双轮走查记录

## 范围与方法

以 Aegis 共享设计技能、已确认的冰川蓝首页材质和用户本轮功能规划为依据。保留当前已实现业务及 mock，不回退到早期占位阶段，不接入真实数据。

检查13个页面入口：`/`、`/monitor`、`/ai`、`/compare`、`/me`、订阅、VIP、代理、收益与绑定、消息、工单、关注、AI历史。每页在390px下分别截取首屏、中段与页尾，并实际查看截图、读取计算字号与布局尺寸。

另检查30个关键状态：首页搜索、监测筛选与平台详情；体育设置、日历、注单匹配、帮助、Bot、提醒、完整比价、试算、排名、计算核验、报告、比赛中心四个tab、足球三项和半全场九项；账户设置；订阅对比、用量和方案；VIP条款和需求；代理试算和需求；AI回答和依据。

第一轮保存39张页面截图与29张功能状态截图；账户设置在第二轮补齐。第二轮重新保存39张页面截图、30个关键状态及长抽屉页尾，重新查看修复后的首屏、中段、页尾和状态合集。360/390/430px另运行全页面UI回归与关键控件检查，桌面检查1440px视口居中最大430px栏。

## 第二轮复查与继续修复

- 重新检查全部13页的顶部、左右对齐、中段表格、末尾操作与固定底栏。已检查页面未发现整页横向溢出；滚到底后末项可完整露出。
- 体育格式选中卡的边框和背景已恢复；港盘、马盘、印尼盘、欧盘的选中状态可区分。
- 三项／九项表格只在表格容器横向滚动，未扩宽整页；订阅三档和对比表继续可用。
- **发现并修复第二轮问题**：字号扩大后，近期战绩中的日期与“主场／客场”在固定66px列中断行。日期列改为按内容确定宽度并禁止拆行；在360/390/430px下重新截图复查。
- **长抽屉页尾继续修复**：新多赛果试算复用了净收益class，但旧样式只在首页试算组件的scoped块中，导致结果与说明挤在一行。将净收益样式提取到共享体育样式，恢复浅绿结果区、26px结果数字和独立说明行；三种移动宽度重新验收。
- 抽屉保持单一主标题、80%最高限制及独立内容滚动；重新检查长抽屉底部的保存、咨询、试算和帮助操作。
- 明确区分视觉图标尺寸与点击容器。体育搜索文本框由完整搜索label承接点击，未将18px字行高度误当作整体点击区。

## 已落地的项目规则

`AGENTS.md` 与 `.cursor/rules/aegis.mdc` 共用 `docs/UI-REVIEW.md`：每次完成页面或功能必须先走查修复，再进行第二轮实际截图复查和修复；发现问题后继续复查受影响视图。测试或打包通过不能替代视觉验收，也不能用本轮记录替代之后任务的新走查。
